# Задача 02. Спрос в Вордстате и новые растения (раз в 2 дня)

Цель: держать в `ops/data/wordstat.json` свежие данные о спросе и добавлять в каталог растения, которые люди реально ищут и которых на сайте еще нет. Не больше двух растений за запуск: качество важнее количества.

Задаче нужен компьютер пользователя: Вордстат открывается во встроенном браузере приложения Claude, где пользователь залогинена в Яндекс.

## Шаг 1. Вордстат

1. Загрузи инструменты встроенного браузера: ToolSearch с запросом `mcp__remote-devices__Claude_Browser__`. Если их нет или компьютер недоступен — пропусти шаг 1, напиши об этом в отчете и переходи к шагу 2 с прошлыми данными из `ops/data/wordstat.json` (если они не старше 14 дней; иначе новых растений не добавляй).
2. Открой https://wordstat.yandex.ru/ (если сайт не разрешен — `request_access`). Если просит войти — остановись: пользователю нужно залогиниться самой. Пароли не проси.
3. Запросы делай через JavaScript на странице Вордстата (это то же, что делает интерфейс):

```js
const q = 'монстера уход';
const r = await fetch('/wordstat/api/getTable', {method: 'POST', headers: {'content-type': 'application/json'},
  body: JSON.stringify({currentDevice: 'desktop,phone,tablet', dbname: 'rus', filters: {region: 'all', tableType: 'popular'},
  searchValue: q, startDate: 'ДД.ММ.ГГГГ', endDate: 'ДД.ММ.ГГГГ'})});
const j = await r.json(); j.totalValue  // число показов за период
```

   Период — последний полный календарный месяц. Делай запросы по одному, с паузой 1–2 секунды.
4. Замерь для каждого растения каталога (`src/data/plants.json`, поле `n`) два запроса: «<название>» и «<название> уход». Для кандидатов (ниже) — те же два.
5. Кандидаты (начальный список; дополняй его связанными запросами из ответа Вордстата, если там есть популярные комнатные растения, которых нет в каталоге): фиалка (сенполия), декабрист (шлюмбергера), алоэ, толстянка (денежное дерево), фикус каучуконосный, кротон (кодиеум), диффенбахия, юкка, сциндапсус (эпипремнум), хойя, сингониум, пилея, фиттония, гиппеаструм, пуансеттия, цикламен, азалия, лимон комнатный, мирт, маранта, строманта, глоксиния, колеус, плющ, аспарагус, циссус, рапис, ховея, кофейное дерево, гардения, стрелиция, эхеверия, хавортия, маммиллярия, пахира, бокарнея, фикус лировидный, калла, эухарис, клеродендрум.
6. Сохрани в `ops/data/wordstat.json`:

```json
{"updated": "ГГГГ-ММ-ДД", "period": "ДД.ММ.ГГГГ–ДД.ММ.ГГГГ",
 "catalog": {"monstera": {"q": "монстера", "total": 0, "care": 0, "prev_total": 0, "prev_care": 0}},
 "candidates": {"фиалка": {"total": 0, "care": 0, "note": "сенполия"}}}
```

   `prev_*` — значения из прошлого файла (если период тот же — просто переноси). Задача 01 использует рост `total`.

## Шаг 2. Выбор растений

1. Из кандидатов, которых нет в каталоге, выбери до двух с самым большим числом запросов «<название> уход» (порог — не меньше 1 000 в месяц).
2. Исключи: растения из перечня наркосодержащих; растения, которые в РФ почти не продаются для дома; дубли уже существующих профилей под другим именем.
3. Если подходящих нет — ничего не добавляй, это нормальный результат.

## Шаг 3. Факты

Для каждого растения собери данные по первичным источникам (список разрешенных и запрещенных — `ops/RUNBOOK.md`). Минимум три источника, из них хотя бы один — справочник про выращивание в помещении. Удобно поручить сбор субагенту, а затем отдать готовый профиль второму независимому субагенту на проверку (особенно кошки и обработки).

Профиль — блок в `src/data/plants.json` с теми же полями, что у соседей (посмотри любой существующий блок и повтори формат):
- `slug` (латиница, как в других адресах), `n`, `latin`, `aka`, `title` (по образцу «Название: уход в домашних условиях, …», до ~65 знаков без названия сайта), `desc` (короткий характер, 2–4 слова), `level` («Для новичков» или «Средняя»), `tags` (`new`, `cat`, `shade`, `bloom`, `light` — по фактам), `q_light`, `q_water`;
- тексты `char`, `light`, `water`, `hum`, `temp`, `soil`, `prop` — конкретно, с цифрами из источников;
- `probs` — частые беды [симптом, причина]; `facts` — 2–3 интересных факта с источником;
- `cat` (`safe`/`toxic`/`care`) — только по ASPCA, `cat_note`, `cat_url`;
- `src` — пары [короткое название, url];
- `quiz`: `light` (подмножество `bright`, `mid`, `low`), `dry` (переживет пересушку), `easy`, `fussy` (только если капризное), `bloom`, `vibes` (из `clean`, `jungle`, `bloom`, `odd`), `why` (одна фраза), `v` (подпись к каждому vibe).

Добавь запись в `src/partials/cats-data.json` (поля `n`, `l`, `v`, `syn`, `u`, `why`, `more`, `s`; сохрани порядок: safe → toxic → care). Синонимы не должны совпадать с другими растениями (опасные путаницы: «пальма», «папоротник», «орхидея», «лилия» — не используй как синонимы).

Если растение подтвержденно бывает в разборах `src/data/problems.json` (по источнику) — добавь его slug в поле `plants` нужного разбора.

## Шаг 4. Картинка

1. Проверь кредиты Higgsfield (`balance`). Нужно 0,15 на растение. Если не хватает или Higgsfield недоступен — растение не добавляй: сохрани готовый профиль в `ops/drafts/<slug>.json` и напиши в отчете, что нужны кредиты.
2. Генерация — `generate_image`, модель `z_image`, `aspect_ratio` `1:1`, одна за раз. Промпт по образцу: «Realistic studio photo of a <latin + English name> houseplant with <характерные листья/цветы>, in a simple terracotta pot, whole plant and pot in frame, centered, isolated on pure white seamless background, soft light».
3. Перенос: из контейнера CDN Higgsfield недоступен. Открой URL результата во встроенном браузере и в этой вкладке выполни JS: нарисуй `document.images[0]` на canvas 400×400 с белым фоном и верни `canvas.toDataURL('image/jpeg', 0.8).slice(23)` в виде строки `@@<slug>::<base64>##`. Большой ответ инструмент сохранит в файл в папке tool-results — достань base64 оттуда регулярным выражением и декодируй.
4. Вырежи фон: `pip install --break-system-packages rembg onnxruntime` (если нет), затем `rembg.remove(..., session=new_session('u2net'), alpha_matting=True, alpha_matting_foreground_threshold=240, alpha_matting_background_threshold=10)`, обрежь по `getbbox()`, сохрани `src/assets/img/plants/<slug>.webp` (WEBP, quality 86). Убери светлые остатки фона: пиксели с min(R,G,B) > 215 и разбросом каналов < 25 сделай прозрачными. Посмотри результат глазами (Read на PNG-превью на темном фоне): растение похоже на свой вид, нет белых пятен.
5. Если картинка не похожа на растение — одна повторная генерация с уточненным промптом; дальше не трать кредиты, сохрани черновик.

## Шаг 5. Сборка, проверка, публикация

1. `python3 build.py`; `python3 ops/tools/seo_audit.py docs`.
2. Playwright: страница профиля открывается, каталог показывает карточку, квиз работает, на странице про кошек растение находится поиском.
3. Публикация и журнал — по `ops/RUNBOOK.md`. Отчет: что замерено в Вордстате (топ-5 роста), какие растения добавлены и почему, ссылки, что не получилось.
